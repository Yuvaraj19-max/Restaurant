# ☕ Coffee House

A responsive coffee-shop website built with HTML5, CSS3 and JavaScript.

## Features
- Responsive navigation and sections
- Menu search and category filters
- Add coffee to an order
- Quantity reduction and cart total
- Local Storage cart persistence
- Contact form validation
- Toast notifications
- Smooth section navigation

## Tech Stack
HTML5 · CSS3 · JavaScript · Local Storage

## Future Upgrades
The frontend can later be connected to Java Servlets, JDBC/Hibernate and a database for real customer accounts, menu management and orders.
