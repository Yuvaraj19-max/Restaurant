# 🍽️ Find Your Place Restaurant

A responsive restaurant website built with HTML5, CSS3 and JavaScript.

## Features
- Responsive restaurant landing page
- Menu search and category filters
- Add dishes to an order
- Quantity reduction and total calculation
- Local Storage order persistence
- Table booking validation
- Booking details stored locally
- Toast notifications
- Smooth navigation
- Food gallery and customer reviews

## Tech Stack
HTML5 · CSS3 · JavaScript · Local Storage

## Future Upgrades
The frontend can later be connected to Java Servlets, JDBC/Hibernate and PostgreSQL/MySQL for real table reservations, menu management and order processing.
